# Step 1: Install the NEOGOV Extractor Bookmarklet

A **bookmarklet** is a regular browser bookmark that runs a small helper tool on the webpage you are currently viewing instead of taking you to a new website. It does not run in the background and only activates when you click it.

> **Important:** Because GitHub's code viewer blocks clickable JavaScript links inside Markdown files for security, **use our live GitHub Pages landing page (`index.html`)** to drag and drop the button in one second, or use the manual copy-paste method below.

## Method A: Drag-and-Drop (Fastest on Desktop)

1. **Show your browser's Bookmarks Bar:**
   * **Chrome / Edge / Brave / Firefox (Windows/Linux):** Press `Ctrl + Shift + B`.
   * **Chrome / Edge / Brave / Firefox / Safari (Mac):** Press `Cmd + Shift + B`.
2. Open the **Commonwealth Career Co-Pilot Landing Page** (`index.html` on GitHub Pages).
3. Click and hold the blue **`⚡ CWOPA Extractor`** button and **drag it directly onto your Bookmarks Bar**.

## Method B: Manual Copy-and-Paste (Works in Every Desktop Browser)

1. Open [`bookmarklet/CWOPA-Neogov-Extractor.min.txt`](../bookmarklet/CWOPA-Neogov-Extractor.min.txt) and copy the entire single line of code (it starts with `javascript:(async function(){...`).
2. Right-click anywhere on your browser's **Bookmarks Bar** and select **Add page...** or **Add bookmark...**.
3. In the **Name** field, type: `⚡ CWOPA Extractor`
4. In the **URL** (or **Address**) field, paste the copied `javascript:...` code and click **Save**.
