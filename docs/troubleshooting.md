# Troubleshooting Guide

* **Bookmarks Bar Hidden:** Press `Ctrl + Shift + B` (Windows/Linux) or `Cmd + Shift + B` (Mac).
* **Batch Scanner Finds 0 Jobs:** Open **Advanced Exclusions** in the scanner modal and **uncheck** *"Exclude Non-Remote (Keep Telework / Home HQ)"* to include on-site and hybrid roles.
* **JSON Parse Error in Auto-Fill:** Copy only the `{ "Q01": ... }` JSON object without surrounding Markdown code fences (` ```json `).
